# Spring Boot Microservices with JWT Security, API Gateway & Eureka

This repository contains a complete **Spring Boot Microservices Architecture** implementation with:

- ✅ Eureka Service Registry
- ✅ API Gateway
- ✅ JWT Authentication & Authorization
- ✅ Authentication Service (JWT Generation)
- ✅ Employee Microservice
- ✅ Department Microservice
- ✅ Centralized Security at Gateway Level

This project is built for **learning, interview preparation, and real-world microservices understanding**.

---

## 📌 Microservices & Ports

| Service Name        | Port | Description |
|---------------------|------|-------------|
| service-registry    | 8761 | Eureka Service Registry |
| api-gateway         | 8083 | API Gateway with JWT Security |
| auth-service        | 8082 | Authentication & JWT Token Generation |
| employee-service   | 8080 | Employee Microservice |
| department-service | 8081 | Department Microservice |

🔒 Security Implementation
JWT token is generated by auth-service

JWT token is validated at api-gateway

Employee and Department services are secured behind the Gateway

Direct access to backend services is blocked

Unauthorized access returns 401 Unauthorized
